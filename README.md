# LBCO Digital Safety App

Original LBCO safety forms app (static site, no build step). Open `index.html` or host on GitHub Pages.

- Home menu: Daily Forms, Inspections, Permits, Employee Management, App Admin
- Working forms with checklists and signature, saved in the browser (localStorage), CSV export
- Work site admin (add / update / delete); document links for Safe Job Procedures, H&S Manual, OHS Legislation

Note: data is stored per browser. For shared company-wide records, connect `store` in `app.js` to a backend (e.g. SharePoint/Power Automate).
